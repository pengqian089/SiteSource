# Markdown 语法指南

Markdown 是一种轻量级标记语言，让您能够使用纯文本格式编写文档，然后转换成结构化的 HTML。它以简洁的语法和出色的可读性著称，是程序员、技术写作者和内容创作者的首选工具。

## 概述

几乎所有 Markdown 应用程序都支持 John Gruber 原始设计文档中定义的基本语法。不过，不同的 Markdown 处理器在实现细节上可能存在微妙差异，本指南会尽可能标注这些差异，帮助您编写出兼容性更好的文档。

---

## 标题 (Headers)

标题是文档结构的基础。通过在文字前添加 `#` 号，您可以创建 6 个不同级别的标题，就像 HTML 中的 `<h1>` 到 `<h6>` 标签一样。

### 基本语法

| Markdown 语法 | HTML 代码 | 渲染效果 |
|--------------|-----------|----------|
| `# 一级标题` | `<h1>一级标题</h1>` | <h1>一级标题</h1> |
| `## 二级标题` | `<h2>二级标题</h2>` | <h2>二级标题</h2> |
| `### 三级标题` | `<h3>三级标题</h3>` | <h3>三级标题</h3> |
| `#### 四级标题` | `<h4>四级标题</h4>` | <h4>四级标题</h4> |
| `##### 五级标题` | `<h5>五级标题</h5>` | <h5>五级标题</h5> |
| `###### 六级标题` | `<h6>六级标题</h6>` | <h6>六级标题</h6> |

### 替代语法

对于一级和二级标题，您还可以使用以下替代语法：

| Markdown 语法 | HTML 代码 | 渲染效果 |
|--------------|-----------|----------|
| `一级标题`<br/>`========` | `<h1>一级标题</h1>` | <h1>一级标题</h1> |
| `二级标题`<br/>`--------` | `<h2>二级标题</h2>` | <h2>二级标题</h2> |

### 最佳实践

**正确做法：**
- `#` 号与标题文字之间务必添加空格
- 标题前后各留一个空行
- 使用有意义的标题层级结构

**避免的做法：**
- `#标题` (缺少空格)
- 跳跃式的标题层级 (如从 `#` 直接跳到 `###`)

```markdown
✅ 推荐写法
# 这是一级标题

## 这是二级标题

❌ 不推荐写法
#这是一级标题
##这是二级标题
```

## 段落 (Paragraphs)

段落是文档的基本构成单位。在 Markdown 中，段落由一个或多个连续的文本行组成，通过空行进行分隔。

### 基本语法

```markdown
这是第一个段落。段落可以包含多个句子，它们会被渲染成一个连续的文本块。

这是第二个段落。注意段落之间需要用空行分隔。
```

**渲染效果：**

这是第一个段落。段落可以包含多个句子，它们会被渲染成一个连续的文本块。

这是第二个段落。注意段落之间需要用空行分隔。

### 最佳实践

**正确做法：**
- 段落左对齐，不要使用空格或制表符缩进
- 段落之间用空行分隔

**避免的做法：**
- 在段落前添加不必要的空格或制表符

## 换行 (Line Breaks)

有时您需要在不创建新段落的情况下换行。Markdown 提供了几种方法来实现换行。

### 推荐方法

在行尾添加两个或更多空格，然后按回车键：

```markdown
这是第一行。  
这是第二行。
```

**渲染效果：**

这是第一行。  
这是第二行。

### 替代方法

使用 HTML 的 `<br>` 标签：

```markdown
这是第一行。<br>
这是第二行。
```

### 最佳实践

推荐使用两个空格的方法，因为：
- 兼容性最好
- 符合 Markdown 的设计哲学
- 在大多数编辑器中有可视化指示

## 文本强调 (Emphasis)

通过粗体、斜体等格式来强调重要内容，让您的文档更有层次感。

### 粗体文本

使用两个星号或下划线包围文字：

| Markdown 语法 | HTML 代码 | 渲染效果 |
|--------------|-----------|----------|
| `**重要内容**` | `<strong>重要内容</strong>` | **重要内容** |
| `__重要内容__` | `<strong>重要内容</strong>` | **重要内容** |
| `这个**词语**很重要` | `这个<strong>词语</strong>很重要` | 这个**词语**很重要 |

### 斜体文本

使用一个星号或下划线包围文字：

| Markdown 语法 | HTML 代码 | 渲染效果 |
|--------------|-----------|----------|
| `*强调内容*` | `<em>强调内容</em>` | *强调内容* |
| `_强调内容_` | `<em>强调内容</em>` | *强调内容* |
| `这个*词语*需要强调` | `这个<em>词语</em>需要强调` | 这个*词语*需要强调 |

### 粗体加斜体

使用三个星号或下划线：

| Markdown 语法 | HTML 代码 | 渲染效果 |
|--------------|-----------|----------|
| `***非常重要***` | `<strong><em>非常重要</em></strong>` | ***非常重要*** |
| `___非常重要___` | `<strong><em>非常重要</em></strong>` | ***非常重要*** |
| `这个***词语***极其重要` | `这个<strong><em>词语</em></strong>极其重要` | 这个***词语***极其重要 |

### 最佳实践

为了最佳兼容性：
- 在单词内部使用星号而不是下划线
- 在强调符号和文字之间不要添加空格

```markdown
✅ 推荐写法
这个**词语**很重要
这个*词语*需要强调

❌ 不推荐写法
这个__词语__很重要
这个_词语_需要强调
```

## 引用块 (Blockquotes)

引用块用于标注引用的内容、重要说明或摘录文字。

### 基本语法

在段落前添加 `>` 符号：

```markdown
> 这是一个引用块。它通常用来引用他人的话语或重要的说明。
```

**渲染效果：**

> 这是一个引用块。它通常用来引用他人的话语或重要的说明。

### 多段落引用

在段落之间的空行也要添加 `>` 符号：

```markdown
> 这是引用的第一段。
>
> 这是引用的第二段。
```

**渲染效果：**

> 这是引用的第一段。
>
> 这是引用的第二段。

### 嵌套引用

使用多个 `>` 符号创建嵌套引用：

```markdown
> 这是外层引用。
>
> > 这是嵌套的引用。
>
> 回到外层引用。
```

**渲染效果：**

> 这是外层引用。
>
> > 这是嵌套的引用。
>
> 回到外层引用。

### 包含其他元素的引用

引用块可以包含其他 Markdown 元素：

```markdown
> #### 重要提示
>
> - 这是第一点
> - 这是第二点
>
> *所有内容*都按照**预期**进行。
```

**渲染效果：**

> #### 重要提示
>
> - 这是第一点
> - 这是第二点
>
> *所有内容*都按照**预期**进行。

## 列表 (Lists)

列表是组织信息的绝佳方式，Markdown 支持有序列表和无序列表。

### 有序列表

使用数字加英文句点创建有序列表：

```markdown
1. 第一项
2. 第二项
3. 第三项
   1. 嵌套项目 1
   2. 嵌套项目 2
4. 第四项
```

**渲染效果：**

1. 第一项
2. 第二项
3. 第三项
   1. 嵌套项目 1
   2. 嵌套项目 2
4. 第四项

### 无序列表

使用破折号 (`-`)、星号 (`*`) 或加号 (`+`) 创建无序列表：

```markdown
- 第一项
- 第二项
- 第三项
  - 嵌套项目
  - 另一个嵌套项目
- 第四项
```

**渲染效果：**

- 第一项
- 第二项
- 第三项
  - 嵌套项目
  - 另一个嵌套项目
- 第四项

### 列表中的其他元素

#### 段落

在列表项下缩进四个空格或一个制表符：

```markdown
1. 第一项

   这是第一项下的段落内容。

2. 第二项

   这是第二项下的段落内容。
```

#### 代码块

在列表项下缩进八个空格或两个制表符：

```markdown
1. 打开文件
2. 找到以下代码块：

        <html>
          <head>
            <title>示例</title>
          </head>
        </html>

3. 修改标题
```

#### 引用块

```markdown
1. 第一项
2. 第二项

   > 这是第二项下的引用块。

3. 第三项
```

#### 图片

```markdown
1. 打开包含图片的文件
2. 欣赏其美丽：

   ![示例图片](https://example.com/image.jpg)

3. 关闭文件
```

### 特殊情况：数字开头的无序列表

如果需要以数字开头的无序列表项，使用反斜杠转义：

```markdown
- 1968\. 伟大的一年！
- 我认为 1969 年是第二好的。
```

### 最佳实践

- 在同一列表中保持使用相同的符号
- 列表前后留空行
- 嵌套列表项适当缩进

## 代码 (Code)

代码是技术文档的重要组成部分。Markdown 提供了行内代码和代码块两种表示方法。

### 行内代码

使用反引号包围代码：

```markdown
在命令行中输入 `npm install` 来安装依赖。
```

**渲染效果：**

在命令行中输入 `npm install` 来安装依赖。

### 转义反引号

如果代码本身包含反引号，使用双反引号：

```markdown
``在代码中使用 `反引号` 的方法``
```

**渲染效果：**

``在代码中使用 `反引号` 的方法``

### 代码块

#### 缩进式代码块

使用四个空格或一个制表符缩进：

```markdown
    function hello() {
        console.log("Hello, World!");
    }
```

#### 围栏式代码块（推荐）

使用三个反引号创建代码块，可以指定语言进行语法高亮：

````markdown
```javascript
function hello() {
    console.log("Hello, World!");
}
```

```python
def hello():
    print("Hello, World!")
```

```css
.header {
    background-color: #f0f0f0;
    padding: 20px;
}
```
````

### 常用语言标识符

- `javascript` 或 `js`
- `python` 或 `py`
- `java`
- `csharp` 或 `cs`
- `cpp` 或 `c++`
- `html`
- `css`
- `sql`
- `json`
- `xml`
- `bash` 或 `shell`

## 分隔线 (Horizontal Rules)

分隔线用于在文档中创建主题分隔或视觉分割。

### 语法

使用三个或更多的星号、破折号或下划线：

```markdown
***

---

___
```

以上三种方式的渲染效果相同：

---

### 最佳实践

为了避免与标题语法冲突，分隔线前后都要留空行：

```markdown
✅ 推荐写法
这是一段文字。

---

这是另一段文字。

❌ 不推荐写法
这是一段文字。
---
这是另一段文字。
```

## 链接 (Links)

链接是连接不同内容的重要工具。Markdown 提供了多种创建链接的方法。

### 基本链接

使用方括号包围链接文字，圆括号包围 URL：

```markdown
访问 [我的网站](https://core.dpangzi.com)
```

**渲染效果：**

访问 [我的网站](https://core.dpangzi.com)

### 带标题的链接

在 URL 后添加标题，当鼠标悬停时显示：

```markdown
访问 [我的网站](https://core.dpangzi.com "欢迎来到我的网站")
```

**渲染效果：**

访问 [我的网站](https://core.dpangzi.com "欢迎来到我的网站")

### 自动链接

直接用尖括号包围 URL 或邮箱地址：

```markdown
<https://core.dpangzi.com>
<pengqian089@hotmail.com>
```

**渲染效果：**

<https://core.dpangzi.com>  
<pengqian089@hotmail.com>

### 格式化链接

链接可以与其他格式结合使用：

```markdown
我喜欢访问 **[GitHub](https://github.com)**。
这是 *[Markdown 指南](https://www.markdownguide.org)*。
查看 [`代码`](#代码-code) 部分。
```

**渲染效果：**

我喜欢访问 **[GitHub](https://github.com)**。  
这是 *[Markdown 指南](https://www.markdownguide.org)*。  
查看 [`代码`](#代码-code) 部分。

### 引用式链接

当文档中有很多链接时，引用式链接能让文档更整洁：

```markdown
这是 [引用式链接][1] 的示例。
你也可以使用 [数字以外的标识符][链接标识符]。

[1]: https://www.example.com
[链接标识符]: https://www.another-example.com "可选的标题"
```

### 内部链接

链接到文档内的其他部分：

```markdown
- [跳转到标题部分](#标题-headers)
- [跳转到代码部分](#代码-code)
- [跳转到图片部分](#图片-images)
```

### 最佳实践

为了更好的兼容性：
- URL 中的空格用 `%20` 代替
- 使用有意义的链接文字
- 避免使用 "点击这里" 等通用文字

## 图片 (Images)

图片能让文档更生动。Markdown 的图片语法与链接类似，只是在前面加了感叹号。

### 基本语法

```markdown
![替代文字](图片URL "可选标题")
```

例如：

```markdown
![美丽的风景](https://example.com/landscape.jpg "山川美景")
```

### 本地图片

```markdown
![本地图片](./images/screenshot.png)
```

### 图片链接

将图片包装在链接中：

```markdown
[![GitHub Logo](https://github.com/logo.png)](https://github.com)
```

### 控制图片大小

Markdown 本身不支持设置图片大小，但可以使用 HTML：

```html
<img src="https://example.com/image.jpg" alt="图片描述" width="300" height="200">
```

### 图片最佳实践

- 始终提供有意义的替代文字 (alt text)
- 使用相对路径引用本地图片
- 考虑图片的加载速度和文件大小
- 为图片添加描述性标题

## 表格 (Tables)

表格是展示结构化数据的好方法。虽然表格不是基本 Markdown 语法的一部分，但大多数应用程序都支持。

### 基本语法

使用管道符 (`|`) 分隔列，使用连字符创建表头：

```markdown
| 姓名 | 年龄 | 城市 |
|------|------|------|
| 张三 | 25   | 北京 |
| 李四 | 30   | 上海 |
| 王五 | 28   | 广州 |
```

**渲染效果：**

| 姓名 | 年龄 | 城市 |
|------|------|------|
| 张三 | 25   | 北京 |
| 李四 | 30   | 上海 |
| 王五 | 28   | 广州 |

### 对齐方式

使用冒号控制对齐：

```markdown
| 左对齐 | 居中对齐 | 右对齐 |
|:-------|:--------:|-------:|
| 文本   |   文本   |   文本 |
| 更多文本 |  更多文本  | 更多文本 |
```

**渲染效果：**

| 左对齐 | 居中对齐 | 右对齐 |
|:-------|:--------:|-------:|
| 文本   |   文本   |   文本 |
| 更多文本 |  更多文本  | 更多文本 |

### 表格中的格式

表格单元格可以包含其他 Markdown 格式：

```markdown
| 功能 | 语法 | 示例 |
|------|------|------|
| **粗体** | `**文本**` | **重要** |
| *斜体* | `*文本*` | *强调* |
| `代码` | `` `代码` `` | `function()` |
| [链接](https://example.com) | `[文字](URL)` | [访问](https://example.com) |
```

### 转义管道符

如果需要在表格中显示管道符，使用反斜杠转义：

```markdown
| 名称 | 语法 |
|------|------|
| 管道符 | `\|` |
```

## HTML 支持

Markdown 允许在文档中直接使用 HTML 标签，这为您提供了更多的格式化选项。

### 基本用法

```markdown
这是 **Markdown** 粗体，这是 <strong>HTML</strong> 粗体。

这是 *Markdown* 斜体，这是 <em>HTML</em> 斜体。
```

**渲染效果：**

这是 **Markdown** 粗体，这是 <strong>HTML</strong> 粗体。

这是 *Markdown* 斜体，这是 <em>HTML</em> 斜体。

### 常用 HTML 标签

#### 文本颜色

```html
<span style="color: red;">红色文字</span>
<span style="color: blue;">蓝色文字</span>
```

#### 文本对齐

```html
<div align="center">居中文本</div>
<div align="right">右对齐文本</div>
```

#### 上标和下标

```html
E = mc<sup>2</sup>
H<sub>2</sub>O
```

#### 键盘按键

```html
按 <kbd>Ctrl</kbd> + <kbd>C</kbd> 复制
```

#### 详情折叠

```html
<details>
<summary>点击展开</summary>
这里是隐藏的内容。
</details>
```

### HTML 最佳实践

- 对于简单格式，优先使用 Markdown 语法
- 在 HTML 块级元素前后留空行
- 不要在 HTML 标签内混用 Markdown 语法
- 考虑平台兼容性，某些平台可能限制 HTML 使用

## 数学公式 (Math)

许多 Markdown 应用程序支持 LaTeX 风格的数学公式。

### 行内公式

使用单个 `$` 包围：

```markdown
这是行内公式：$E = mc^2$
```

### 块级公式

使用双 `$` 包围：

```markdown
$$
\sum_{i=1}^{n} x_i = x_1 + x_2 + \cdots + x_n
$$
```

### 常用数学符号

```markdown
- 分数：$\frac{a}{b}$
- 根号：$\sqrt{x}$，$\sqrt[n]{x}$
- 指数：$x^2$，$x^{n+1}$
- 下标：$x_1$，$x_{i+1}$
- 求和：$\sum_{i=1}^{n}$
- 积分：$\int_a^b f(x)dx$
- 极限：$\lim_{x \to \infty}$
```
